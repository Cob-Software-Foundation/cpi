Use farmer instead

You don't need this page to install a package — it's here for browsing. From your project directory: 

farmer harvest <package-name>

resolves against $COB_FARMER_BASE_URL (defaults to this site), verifies the package's sha256, and unzips it into cob_modules/<package-name>/.
